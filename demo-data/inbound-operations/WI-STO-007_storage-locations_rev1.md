# WI-STO-007 Storage Location Rules, Aisles A-10 to A-20 (Revision 1)

> Synthetic demonstration document. Kestrova Components GmbH is a fictional company. Not for operational use.

## 1 Scope

This work instruction applies only to the Hamburg-Billbrook site (HAM-02), aisles A-10 to A-20.

## 2 Storage classes

- Locations A-10 to A-13 are for storage class 1 (non-hazardous, palletised).
- Locations A-14 to A-17 are for storage class 2 (small parts in bins, maximum 25 kg per bin).
- Locations A-18 to A-20 are for storage class 3 (temperature-sensitive material, 15 to 25 °C).

## 3 Rules

Check the storage class in the material master before putaway. Material of an unknown storage class is not put away in aisles A-10 to A-20; ask the shift lead.
